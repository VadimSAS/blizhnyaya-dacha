# Ближняя Дача

Статический прототип B2B-сайта. Откройте dist/index.html или разместите содержимое dist на статическом хостинге. Сборка и зависимости не требуются.

- 18 реальных упаковок и оригинальный логотип: https://kfh-m.ru/
- 3 иллюстрации созданы встроенным ImageGen для визуального макета. Это не фотографии реального производства.
- Форма демонстрационная, данные никуда не отправляет. PDF-каталог и документы пока запрашиваются через демонстрационный сценарий.
- Перед запуском: реальные контакты, реквизиты, политика персональных данных, согласование заявленных характеристик и подключение формы.

## Медиа

dist/assets/hero-food.webp — овощи, ягоды и крокеты на светлом столе; packing-concept.webp — концепция фасовочной линии; production-concept.webp — концепция линии заморозки.

Промпты: натуральная предметная съёмка овощей и ягод в керамических мисках на шалфейном столе; чистая нержавеющая линия фасовки с овощами и белыми пакетами; конвейер замороженных брокколи, моркови и горошка. Без логотипов, текста и сертификационных обозначений.
